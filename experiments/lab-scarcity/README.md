## อ่านอย่างระวัง

- ชั่วโมง "Lab ไม่จำเป็น" ของ fixed **ลดลง** เมื่อ Lab น้อยลง (2,010 → 1,558 → 1,062 ชม.) เพราะคาบที่จัดไม่ได้มากขึ้น ไม่ได้แปลว่าใช้ Lab ดีขึ้น ให้อ่านคู่กับคาบที่ยังจัดไม่ได้เสมอ
- เป็นการตัดห้องที่เล็กที่สุดออกแบบเดียว ไม่ได้ลองทุกชุดของห้องที่เหลือ และใช้ 10 seeds ต่อกรณีตาม protocol
