## อ่านผลอย่างไร

- **ห้องคงที่ทำให้ Lab ถูกครองโดยไม่ได้ใช้เพิ่มราว 1,800 ชม. ต่อเทอม** (ราว 1,925–1,980 ชม. เทียบกับ 124–141 ชม.) ทุกวิธี ทุก seed สอดคล้องกับตัวอย่างในสไลด์: คาบที่ต้องใช้ Lab 4 สัปดาห์ แต่ห้องคงที่ครอง Lab ไว้ทุกสัปดาห์ที่จัดได้
- **ห้องคงที่ยังจัดคาบไม่ได้มากขึ้นมาก** (240–390 จาก 3,345 คาบ เทียบกับ 0–20) เพราะ Lab 4 ห้องรองรับคาบที่ต้องใช้ Lab แบบจองทั้งเทอมไม่พอ ตัวเลข "Lab ไม่จำเป็น" ของ fixed นับเฉพาะสัปดาห์ที่จัดได้ จึงเป็นค่าต่ำกว่าความต้องการจริงหากต้องจัดให้ครบ
- **ราคาของ weekly คือการเปลี่ยนห้อง** ราว 840–860 ครั้งต่อเทอม (fixed = 0 ตามนิยาม) ซึ่งเป็นเป้าหมายลำดับที่ 3 ในการจัดอันดับ
- ตารางนี้เป็น descriptive summary ยังไม่ได้ทำ significance test (รอ protocol ใน #4 และสคริปต์วิเคราะห์ใน #7)

## รันซ้ำ

```sh
python3 python/cli.py --room-modes weekly fixed --methods greedy hc sa ga \
  --budget 50 --seconds 600 --seed 1001 --repeats 30 --output results/fixed-room
python3 python/compare_modes.py results/fixed-room/experiment-*.json
```

คำสั่งแรกรันทั้งสองโหมดใน process เดียว (ราว 40–45 นาที) ผลชุดนี้แบ่งเป็น 4 process ตามโหมดและครึ่งของ seed (`--room-modes weekly --seed 1001 --repeats 15` เป็นต้น) แล้วรวมด้วย `compare_modes.py` ซึ่งรับหลายไฟล์และไม่ยอมรับรันซ้ำ (algorithm, mode, seed) ผลจะตรงกันเมื่อใช้ dataset/code/parameters/Python เดียวกันและไม่มีรันโดน time cap
