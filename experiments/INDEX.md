# ผลทดลองทั้งหมด

ทุกชุดใช้ชุดข้อมูล Fall CS Weekly Labs v2 (`data/fall-cs.json.gz`) หรือชุดแปรใน `data/variants/` และรันใหม่ทั้งหมดเมื่อ 2026-11-19 ด้วย engine C# กติกาอยู่ใน [docs/protocol.md](../docs/protocol.md) ตัวเลขในตารางคัดมาจาก README ของแต่ละชุด

ความต้องการ Lab ในชุดข้อมูลสร้างขึ้นเอง (assumption A10) ผลทั้งหมดจึงเป็นการศึกษาโจทย์ที่ตั้งขึ้น ไม่ใช่ข้อค้นพบเกี่ยวกับมหาวิทยาลัยจริง

|---|---|---|---|---|
| [tuning](tuning/README.md) (#5) | พารามิเตอร์ของ HC, SA และ GA | 1–10, งบ 500 | ลอง 51 ชุดค่า (510 รัน) กฎขยายขอบทำงานหนึ่งครั้งกับ SA ค่าที่ล็อก: HC patience 200, SA เท่าค่าเริ่มต้น, GA ชุด `ga-15` | `configs/`, `tuning-summary.csv`, `summary.md`, `selected-parameters.json` |

นำไฟล์ `.json.gz` ทุกไฟล์เข้าเว็บได้โดยตรง (หรือ gunzip ก่อน) และ `manifest.json` ของแต่ละชุดบันทึก SHA-256 ของ dataset และ engine ที่ใช้

ผลทั้งหมดผลิตด้วย engine C# ซึ่งเป็นตัวแก้ปัญหาตัวเดียวใน repo ก่อนลบตัวแก้ปัญหาภาษา Python ออกจาก repo ได้รัน 16 รันของการทดลองสุดท้าย (4 วิธี × 2 โหมดห้อง × seed 1001–1002) ด้วยตัวนั้นบนชุดข้อมูลใหม่ ได้ metric ตารางคำตอบ และ trace ตรงกับผลของ C# ทุกรัน การตรวจนี้ทำซ้ำจากโค้ดปัจจุบันไม่ได้แล้ว ตัวแก้ปัญหาภาษา Python อยู่ใน git history เท่านั้น (มีอยู่ครั้งสุดท้ายที่ commit 6d33611 บน main) ไม่มีการวัดเวลาเทียบกัน
