เว็บสไลด์ภาษาไทย 30 หน้า พร้อมบทพูดทุกหน้า มี deck เดียว เปิดที่ `/` ไม่มี dependency

หน้าตาแบบวาดมือ: พื้นขาว ฟอนต์ Mali เส้นหมึกดำ สีเหลืองสีเดียว และตัวการ์ตูนจอคอมพิวเตอร์ แต่ละหน้าเป็นผืน 1920×1080 ที่ย่อขยายให้พอดีหน้าต่าง

ผลทั้งหมดมาจากข้อมูลชุด `pu-fal07-cs-weekly-lab-v2` (ความต้องการ Lab เป็นรายวิชา เฉพาะส่วนปฏิบัติ) และรันด้วย engine C# เมื่อ 19 พ.ย. 2026

## กติกาของ deck

- **ไม่มีตัวอย่างสมมติ** ทุกแถบ ทุกกราฟ และทุกตัวเลข วาดจากข้อมูลจริง (`data/fall-cs.json.gz`) หรือจากรันที่เก็บไว้ (`experiments/`) มีป้ายบอกกลุ่มเรียน ห้อง และรันที่มา และ `build.py` ตรวจทุกครั้งที่ build ถ้าข้อมูลไม่ตรงกับที่หน้าบอก build จะหยุด คำว่า "สมมติ" ใช้เฉพาะกับส่วนของข้อมูลที่จำลองขึ้น (ห้อง Lab 4 ห้อง และความต้องการ Lab)
- **หนึ่งหน้า หนึ่งภาพ** ไม่มีกล่องข้อความวางซ้ายขวา รายการสั้นไม่เกิน 3 ข้อ คำอธิบายอยู่ในบทพูด
- **ใต้ภาพมีได้บรรทัดสั้นบรรทัดเดียว** บอกว่าภาพคืออะไร เช่น `Greedy, วันศุกร์ 8:30` คำอธิบายสัญลักษณ์เป็นช่องตัวอย่างกับคำหนึ่งหรือสองคำ (`legend()`) ไม่ใช่ประโยค รายละเอียดอื่นอยู่ในบทพูดหรือบล็อกถามตอบ
- **ตัวอักษรที่ผู้ชมต้องอ่าน ไม่เล็กกว่า 32px** บนผืน 1920×1080 ยกเว้นเลขหน้า และรายการเอกสารอ้างอิงสามหน้าท้าย
- **สีมีความหมายเดียวทั้ง deck และมีข้อความกำกับซ้ำเสมอ** ใช้สีทึบเข้ม ตัวอักษรขาว ไม่ใช้สีอ่อนและไม่ใช้ลายเส้น
  - น้ำเงิน `#1D4ED8` = อยู่ห้อง Lab ในสัปดาห์ที่ต้องใช้ และค่าที่ดีในกราฟผล (ป้าย เช่น `L4`, `0.0`)
  - แดง `#B91C1C` = Lab ไม่จำเป็น, ไม่มีห้อง และแท่งของ Greedy (ป้าย เช่น `(L4)` ในวงเล็บ, `ไม่มี`)
  - เทา `#4B5563`, เทาอ่อน `#E5E7EB` และขาว = ห้องบรรยาย หรือค่ากลาง
  - น้ำเงินกับแดงสว่างใกล้กัน ช่องที่อยู่ติดกันจึงต้องมีรหัสในช่องเสมอ สีเหลืองเป็นแค่ของตกแต่ง ไม่มีความหมาย
- **กรอบคำพูดติดกับตัวการ์ตูนเสมอ** สร้างผ่าน `duo()` ที่เดียว ซึ่งหยุด build ถ้าปลายหางของกรอบห่างจากหัวตัวการ์ตูนเกิน 30px ในหน้าผลการทดลอง ตัวการ์ตูนยืนอยู่ในข้อมูล (บนแท่ง ข้างแถวของตาราง ปลายเส้นกราฟ)
- **คำที่ใช้** กลุ่มเรียน = section, คาบ = เวลาเรียนหนึ่งครั้งต่อสัปดาห์ (223), ช่อง = หนึ่งคาบในหนึ่งสัปดาห์ (3,345), Lab ไม่จำเป็น = นั่งอยู่ในห้อง Lab ในสัปดาห์ที่ไม่ต้องใช้คอม

## ไฟล์

- `index.html`: หน้าเว็บของ deck โหลด `style.css`, `simple/simple.css` และ `simple/deck.js`
- `style.css`: ค่าเริ่มต้นของผืนสไลด์ (div = flex column, ระยะขอบข้อความ 0) แถบควบคุม และอนิเมชัน
- `simple/build.py`: เนื้อหาทุกหน้าอยู่ที่นี่ที่เดียว `SLIDES` เก็บหัวข้อและเนื้อหา `NOTES` เก็บบทพูด และลำดับ key ของ `NOTES` คือลำดับหน้า
- `simple/controller.js`: ตัวควบคุมสไลด์ (เปลี่ยนหน้า สารบัญ เต็มจอ โน้ตผู้พูด ย่อขยาย)
- `simple/simple.css`: ฟอนต์ เส้นตาราง และแผงโน้ตผู้พูด
- `simple/slides.json`, `simple/deck.js`, `simple/speaker-notes.md`: ไฟล์ที่ `build.py` สร้าง ห้ามแก้มือ
- `simple/index.html`: ส่งลิงก์เก่าของ `simple/` มาที่หน้าแรก โดยคงเลขหน้าไว้

## บทพูด

- เป็นภาษาพูดของผู้นำเสนอ ใช้ "เรา" กับงาน ไม่ใช่บทสรุป
- บทหลักของแต่ละหน้าพูดตัวเลขไม่เกินสองตัว และบอกว่าให้ดูอะไรก่อน ภาพเป็นคนแบกตัวเลขที่เหลือ
- หน้าเทคนิค (พารามิเตอร์ สถิติ การตรวจซ้ำ) บทหลักพูดแค่ข้อสรุป รายละเอียดอยู่ในบล็อกถามตอบ
- ข้อความใน `[วงเล็บเหลี่ยม]` คือท่าชี้ บอกตำแหน่งหรือข้อความที่พิมพ์อยู่บนหน้า ไม่บอกสี ไม่ต้องอ่านออกเสียง
- หน้าที่อาจารย์น่าจะถามต่อ มีบล็อก "ถ้าอาจารย์ถาม" ต่อท้าย เป็นคู่ ถาม และ ตอบ ไม่นับในเวลาพูด
- `build.py` พิมพ์จำนวนตัวอักษรของบทหลักแต่ละหน้า (ไม่นับท่าชี้และบล็อกถามตอบ) และเตือนเมื่อรวมเกิน 6,800 ตัวอักษร ซึ่งตั้งเป้าไว้ที่ประมาณ 15 นาที ยังไม่ได้จับเวลาพูดจริง

## แก้เนื้อหา

แก้ใน `simple/build.py` แล้วรัน

```
python apps/slides/simple/build.py
```

สคริปต์ใช้ standard library อย่างเดียว และจะหยุดพร้อมข้อความเมื่อ

- `SLIDES`, `NOTES` หรือ `CITES` อ้าง id ที่ไม่ตรงกัน
- ข้อมูลหรือรันที่เก็บไว้ ไม่ตรงกับสิ่งที่หน้าใดหน้าหนึ่งวาดหรือบอก (ดู `check()`)
- ค่าปลายเส้นของหน้า 14 ถึง 16 ไม่เท่ากับค่าเฉลี่ยใน `report.md`
- กรอบคำพูดอยู่ห่างจากตัวการ์ตูนของมัน

ท้าย build จะพิมพ์ค่าของเส้นกราฟที่ครั้งที่ 1, 50, 100, 200, 300 และ 500 ของแต่ละวิธี ไว้ให้ตรวจ

## เปิดใช้งาน

เปิด `index.html` ได้โดยตรง หรือรัน `python -m http.server 8766 --directory apps/slides` แล้วเปิด http://localhost:8766/

- ลูกศรขวา หรือ Space: หน้าถัดไป
- ลูกศรซ้าย: ย้อน
- Home และ End: หน้าแรกและหน้าสุดท้าย
- F: เต็มจอ
- N หรือปุ่ม "โน้ตผู้พูด (N)": เปิดและปิดบทพูดของหน้าปัจจุบันใต้สไลด์ (ปิดไว้ทุกครั้งที่เปิดหน้าเว็บ)
- สารบัญเลือกหน้า และลิงก์ `#N` เปิดหน้าที่ N
- ฟอนต์โหลดจาก Google Fonts ถ้าออฟไลน์จะใช้ฟอนต์สำรองของเครื่อง
- เครื่องที่ตั้ง "ลดการเคลื่อนไหว" (prefers-reduced-motion) จะไม่มีอนิเมชัน
